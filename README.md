## Мини-приложение для поиска треков на itunes.apple.com, а также прослушивания превью найденных треков.
## Стек: UIKit, VIPER, UITableView, UISearchBar, AVFoundation, URLSession.

### Search module
**Search module** отвечает за отображение экрана поиска треков. Он содержит таблицу с результатами поиска и поле для ввода поискового запроса.

Ожидаемый результат:
- При запуске приложения отображается экран **StartViewController**, выступающий в роли LaunchScreen. В этот момент предполагается выполнение проверкм авторизации пользователя.
- После этого происходит автоматический переход на **MainTabBarController** с активным экраном **SearchViewController** (другие экраны TabBar не реализуются в рамках текущего задания).
- На экране **SearchViewController** отображается таблица (UITableView) с результатами поиска.
- В верхней части экрана размещен поиск (UISearchController), в котором пользователь может ввести ключевые слова.
- Поиск начинается после ввода 3 и более символов.
- аждая ячейка (TrackTableViewCell) отображает обложку, название трека и имя исполнителя.
- При нажатии на ячейку происходит переход к экрану плеера (см. **Player module**).

### TrackTableViewCell
**TrackTableViewCell** — кастомная ячейка таблицы для отображения информации о треке.

Ожидаемый результат:
- В ячейке отображаются обложка трека (слева, с закруглёнными углами), название трека и имя исполнителя (под названием трека).
- Визуальный стиль соответствует общему оформлению приложения.

### Player module
**Player module** отображает экран воспроизведения выбранного трека.

Ожидаемый результат:
- При открытии экрана **PlayerViewController** отображаются обложка, название трека и имя исполнителя.
- На экране также находится кнопка "Play/Pause" для управления воспроизведением.
- При первом нажатии на кнопку — начинается воспроизведение трека.
- При повторном — воспроизведение останавливается.
- Справа от кнопки отображается текущее время воспроизведения и общая длительность трека.
- Экран стилизован в соответствии с дизайном приложения.
